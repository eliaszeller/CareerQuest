# Retro graphics and actionable roadmap

The MVP uses original SVG scenery and CSS for a console-era, low-poly game-world feel: bright terrain, angular mountains, block clouds, dimensional checkpoints, and chunky interface borders. John Business uses the supplied portrait in the character confirmation screen, quest map, and roadmap. Profession/gender avatar choices have been removed from the interface.

The roadmap has four navigable checkpoints and 12 actions. Each action includes completion evidence. Content reflects the target role, student status, route, goal, budget, time horizon, and priorities. High-school plans emphasize advisor-supported exploration and age-appropriate opportunities. Training routes compare options before enrollment, promotion plans request measurable evidence, and business plans test demand before committing money. These are planning prompts, not verified requirements for any profession.

Checkbox progress survives navigation back to the simulation. Generating a new quest or changing the route clears the checklist. Progress remains in memory and clears on refresh; printing preserves a readable copy.

Verification covers student and route-specific content, John Business replacing avatar selection, checklist navigation persistence, checkpoint anchors, desktop/mobile layout, and automated accessibility checks.
